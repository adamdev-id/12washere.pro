✳ REQUIRED BEFORE JOINING SETUP / 01

Install ZombieBuddy.

ZombieBuddy is required. Subscribing on Steam alone is not enough. Follow the setup tutorial before connecting.

  1. Subscribe to ZombieBuddy on Steam Workshop.Steam Workshop ↗
  2. Close Project Zomboid. On Windows, download and run the ZombieBuddy 4.4 installer from the release's Assets section.Windows installer ↗
  3. Finish setup using the tutorial, then launch the game and join 12WASHERE.Watch tutorial ↗

On Linux or macOS? Follow the instructions for your platform on the ZombieBuddy Workshop page.
