✳ REQUIRED BEFORE JOINING SETUP / 01

Prepare your game.

ZombieBuddy is required. Windows players must also run the 12washere.pro Patcher. Complete both installations before connecting; subscribing on Steam alone is not enough.

  1. Subscribe to ZombieBuddy on Steam Workshop.Steam Workshop ↗
  2. Close Project Zomboid. On Windows, download and run the ZombieBuddy 4.4 installer.
    Download ↓ Open GitHub Page ↗
  3. Follow the tutorial to finish the ZombieBuddy setup.Watch tutorial ↗
  4. Run the 12washere.pro Patcher.WINDOWS 10/11 x64 · v1.7.0

    Keep Project Zomboid closed. Download and run the patcher, confirm the detected game folder, then click Patch game. Under Server Mods, open Needs Update and click Sync/Patch Mods from Server. When a release is available, use Play approved release. If none is published yet, open Steam normally and join 12WASHERE.

    Includes spawn descriptions and previews, clothing-slot labels, the outfit preset fix, and the local Autodrive Viewpoint route add-on. Enable routes in Viewpoint: Delete → Add-ons. The EXE alone is enough; Python and the optional ZIPs are not needed.

    Download Patcher (.exe) Instructions and limits

    If the patcher says “Project Zomboid is running,” close the game first. Patch and Restore stay blocked until it is closed.

    Windows only. Approved server mods download through Sync/Patch Mods from Server. ZombieBuddy is installed separately. Already lost outfit selections cannot be recovered. Steam updates can overwrite the fixes; run Verify in the patcher afterward.

    SHA-256 checksums · Optional client package ZIP · Optional local-mod ZIP

On Linux or macOS? Follow the instructions for your platform on the ZombieBuddy Workshop page.
